# План тестирования мобильного приложения "ВХОСПИСЕ"

## Что проверяем
Приложение "ВХОСПИСЕ" для Android. Нужно проверить, что оно работает: вход, новости, цитаты, выход.

## Что не проверяем
Сервер, нагрузку, безопасность - это не входит в задачу.

## Какие тесты делаем
- Функциональные: проверяем, что все кнопки и поля работают.
- UI: проверяем, что элементы отображаются.
- Регрессионные: прогоняем автотесты после изменений.

## Данные для входа
- Логин: login2
- Пароль: password2
- Невалидные данные: пустые поля или случайный пароль.

## Что нужно для работы
- Android Studio
- Espresso для автотестов
- Allure для отчётов
- Эмулятор с Android API 36 (по заданию)

## Этапы
1. Ручное тестирование, составить чек-лист и тест-кейсы.
2. Написать автотесты.
3. Сделать отчёт в Allure.
