# Результаты тестирования

## Сравнение времени
| Подход | Время |
| :--- | :--- |
| Ручное тестирование (58 проверок) | ~8 часов |
| Автотесты (3 кейса) | ~10 минут |

## Найденные проблемы (баги)
1. **Пробелы в логине/пароле не обрезаются**  
   При вводе " login2 " и " password2 " вход выполняется, хотя должна быть ошибка.  
   Приоритет: Medium

2. **Некорректная дата создания (Creation date)**  
   После создания новости 01.08.2026 в поле Creation date отображается 12.07.58551.  
   Приоритет: High

3. **Фильтр без выбора статуса показывает все новости**  
   В Control Panel при фильтрации без выбора Active/Not active система показывает все новости, хотя должна требовать выбора статуса.  
   Приоритет: Medium

## Allure
Allure не удалось подключить из-за отсутствия библиотеки в Maven Central. Вместо Allure использовано логирование шагов через Allure.step() в Page Object'ах.

## Вывод
Автоматизация позволила сократить время проверки приложения с 8 часов до 10 минут. Найдены 3 бага, которые требуют исправления. Часть тестов не удалось автоматизировать из-за особенностей эмулятора и анимаций.
